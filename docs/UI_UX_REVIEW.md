# ZipZip UI·UX 개선 기록

목표는 반디집을 넘어서는 전체 UI·UX다. 아래는 2026-09-09에 구현하고 검증한 개발 작업이며, 목표 전체 달성 판정은 아니다.

## 기준과 실행 환경

- 원본: GPLaider/zipzip, main, b031fe4ced1d6acab6c2549e8b81af9954295aa0.
- 최초 관찰: v0.1.0-preview 설치 빌드. 설치 파일 SHA-256: 98d63bee509a5b8ea3264dd53d08e2f583acaa40d5720b2d14c9182a67bd8119.
- 현재 관찰: 이 작업의 수정 소스를 SDK 8.0.425로 직접 빌드한 Windows x64 앱. 7-Zip 24.09.
- 실제 조작 경로: artifacts/runtime/preview-app/ZipZip.App.exe. 폴더 이름은 preview-app이지만 실행 내용은 수정 빌드다.
- 최초 설치가 시작 메뉴 바로가기·사용자 단위 제거 항목을 만들었다. 파일 연결·탐색기 메뉴 등록은 선택하지 않았다.
- 최초에는 설치된 반디집 6.29의 창 이동·생성 대화상자를 확인했다. 이후 공식 사이트의 반디집 7.46 포터블(파일 버전 7.46.0.1, Bandisoft 서명 Valid)을 별도 D 폴더에서 실행해 같은 implicit.zip을 열고 추출했다. 기본 앱 연결은 변경하지 않았다.

## 구현

- 첨부한 집·지퍼 참고 이미지를 바탕으로 투명 아이콘 원본을 제작하고 앱·12개 파일 형식의 PNG와 9개 크기 ICO 프레임을 통일했다.
- 홈의 작업 카드 폭·간격, 최근 파일 목록과 빈 상태, 글자·버튼 크기·테마 대비를 정리했다.
- 압축 목록을 헤더, 작업, 경로, 파일 목록, 결과 안내 순으로 정리했다. 파일 종류 한글 깨짐을 수정했다.
- 폴더 압축 진입, Enter·Backspace 폴더 탐색, 전역 열기·새 압축 단축키를 추가했다.
- 암호화된 파일 목록의 암호 입력, 추출 작업 암호 재사용, 취소 가능한 작업 창을 연결했다.
- 설정 저장 안내를 아래로 옮겨 테마 버튼 위치가 바뀌지 않게 했다.
- UTF-8 프로세스 출력, 묵시적 상위 폴더 복원, 특수문자 파일 선택, 프로세스 취소·종료 처리를 보완했다.
- 기존 압축 파일에 실수로 추가 저장하는 동작을 차단했다. 잘못된 암호가 빈 파일을 남겨 다음 시도를 건너뛰는 문제를 사전 검증으로 막았다.
- 암호 없는 7-Zip이 stdout에 암호 요청, stderr에 Break signaled를 나누어 기록하는 경우도 GUI 암호 입력으로 연결했다.
- 분할 압축 생성 후 첫 볼륨(.001)을 열도록 수정했다. 생성 입력 검증과 ZIP의 파일 이름 암호화 비활성화를 추가했다.
- CLI 빌드의 PRI 작업 누락을 공식 MSIX 빌드 패키지로 해결하고 재현 가능한 빌드·검증 스크립트를 추가했다.
- 실제 7-Zip 출력에서 진행률을 읽어 퍼센트·경과 시간을 표시한다. 준비 중에는 불확정 표시를 유지하며 취소 후 늦게 도착한 갱신을 무시한다.
- 설정 카드·파일 연결 버튼은 창 폭에 따라 줄바꿈하고, 낮은 창에서는 오른쪽 내용을 스크롤한다.
- Per-Monitor V2 매니페스트를 추가했다. 빌드 실행 파일에 DPI 선언이 포함됨을 확인했다.
- 기존 무결성 검사 엔진을 아카이브 도구 모음에 연결했다. 암호 재입력·진행률·취소를 지원하고 원본을 변경하지 않는다.

## 검증된 결과

- 앱 최종 빌드 오류 0·경고 0. 탐색기 보조 프로그램 빌드 성공(최초 전체 빌드에는 기존 CS1998 경고 1개).
- 기존 자동 테스트 21개 통과.
- 실제 7-Zip 검사 28개 통과: ZIP/7Z 한글 왕복, 기존 출력 보존, 묵시적 폴더, 선택 추출, @/- 파일명, 암호 실패·같은 폴더 재시도, 암호화 목록, 분할 생성·열기, 숫자 진행률, 실행 중 취소·잔여 프로세스 없음, 손상 파일 거부, 정상·암호화·손상 파일 무결성 검사 및 원본 해시 보존.
- 아이콘 13세트·117 ICO 프레임의 크기·투명 모서리·PNG 일치 검사 통과.
- 실제 창에서 홈·최근 파일·아카이브 표시, Ctrl+O, Enter 진입·Backspace 복귀, 암호 입력 후 암호화 목록 열기를 확인했다.
- 실제 창에서 폴더 선택 → ZIP 생성 → 결과 열기 성공. 생성 파일에 7z t 실행 결과 Everything is Ok, 폴더 2개·파일 1개.
- 실제 창에서 전체 추출 완료 안내와 폴더 열기 버튼을 확인하고 출력 파일 내용 nested를 검증했다. 추출 후 탐색 위치도 유지된다.
- 실제 설정 창에서 라이트·시스템 테마 전환 후 저장 안내가 떠도 버튼 위치가 유지됨을 확인했다.
- 128MB 생성 화면에서 41%·경과 00:02를 확인하고 완료 후 결과를 열었다. 512MB 생성 화면에서 28%·경과 00:02를 확인한 다음 실제 취소 버튼으로 종료했고 7z 프로세스가 남지 않았다.
- 실제 설정 창을 632×511로 축소하고 스크롤하여 파일 연결 하단의 다섯 버튼 모두에 접근했다. 적용 버튼은 누르지 않았다.
- 실제 도구 모음의 무결성 검사로 정상 ZIP 통과 안내를 확인했다. 암호 ZIP은 암호 없음 → 오답 입력 → 재입력 → 정답 입력 → 통과까지 확인했다.
- 반디집 7.46에서 동일 implicit.zip 열기 → 풀기 → 대상 입력 → 확인 → 완료를 조작했다. 출력 문서 내용 nested를 확인했다. 단계 수·성능의 우위는 아직 측정하지 않았다.
- 엔진 검사 증거: D:\ZipZip-build\verified\smoke\zipzip-smoke-638fc356a4664688a8e697d722bc1710.

## 알려진 한계와 남은 검증

- 암호화 파일은 추출 전에 전체 무결성 검사를 하므로 두 번 디코딩한다. 대용량 병목이 확인되면 임시 폴더 추출 후 반영 방식으로 바꾼다.
- 취소하면 완성되지 않은 압축 또는 이미 추출한 파일이 남을 수 있다. 사용자 안내는 있지만 원자적 롤백은 없다.
- 수치 진행률과 경과 시간은 구현했다. 전송 속도·남은 시간 추정은 없다.
- 작은 설정 창과 실제 취소 버튼은 검증했다. 여러 모니터의 100/125/150% DPI, 키보드 전체 동선, 파일 연결·탐색기 통합·새 설치 파일은 추가 검증 대상이다.
- 최신 반디집과 기본 열기·해제는 비교했다. 같은 데이터로 오류 복구·속도·접근성을 추가 측정해야 하며 현재 결과로 전체 UI·UX 우위를 주장하지 않는다.
- 커밋·푸시·릴리스는 하지 않았다.

추가 실제 창 검증: Ctrl+N으로 생성 대화상자를 열고 기존 폴더.zip 이름으로 생성을 시도했다. 기존 파일을 변경하지 않고 같은 대화상자에 오류가 표시되며 입력값이 보존됐다.
남은 재현: 자동 조작에서 시작 또는 다른 앱에서 돌아온 뒤 콘텐츠를 클릭하기 전 Ctrl+O가 간헐적으로 동작하지 않는다. 지연된 논리 포커스 복원은 남겼고, 효과가 없던 네이티브 ContentIsland 포커스 우회는 제거했다. 콘텐츠 클릭 후 설정 화면에서도 Ctrl+O·Ctrl+N이 동작한다. 물리 키 입력 결과는 아직 받지 못했다.

## 0.2.0-preview 배포 검증 (2026-09-09)

이 절은 위 개발 단계의 남은 검증·해시·미배포 상태를 갱신한다.

- Windows App SDK 1.8.11(1.8.260804001)로 업데이트했다. 공식 파일 선택창 포커스 복구 수정과 페이지 Loaded 이후 초기 포커스 설정을 적용했다.
- 일반 Windows 셸에서 최종 설치 파일을 실행했다. 설치 및 탐색기 등록 종료 코드 0, 재부팅 불필요, 설치 DLL과 Release 스테이지 DLL 해시 일치.
- 일반 실행 직후 마우스 클릭 없이 Ctrl+O가 열렸다. 실제 Alt+Tab으로 다른 앱을 왕복한 후 Ctrl+N도 열렸다. 자동화 도구의 activate_window만 사용한 경로에서는 실패가 남아 있어 실제 Alt+Tab 결과와 구분한다.
- 100% 기준, 125% 및 150%로 실제 모니터 배율을 변경하고 창을 이동해 목록·파일 선택창 동작을 확인했다. 배율은 원래 100%로 복원했다. 고배율 캡처에 일부 글자 왜곡이 있어 렌더링 선명도 전부를 인증한 것은 아니다.
- 일반 사용자 셸에서 설치·등록하자 탐색기 메뉴가 표시됐다. Codex에서 시작한 등록의 레지스트리 조회만으로는 실제 탐색기 표시를 보장하지 못했다.
- 실제 탐색기 메뉴로 check.txt.zip 생성, 7z t 통과. sample.zip을 새 폴더에 추출해 완료 창과 결과 내용 nested를 확인했다.
- 최종 Release 엔진 검사 28개, 기존 테스트 21개, 아이콘 117프레임 통과. 앱 빌드 오류·경고 0, 셸 보조 프로그램은 기존 CS1998 경고 1개.
- 설치본: ZipZip-Setup-0.2.0-preview.exe, 84,763,527 bytes. SHA-256: 549700a78a396a0f9f6e0df3387afd944dd9c70ac03fcf67fe6b7551cea995b3.
- 최종 앱 DLL SHA-256: 979b52140e6f6ce7103285a22f2b22aba6504a488293fdf646aa82fa6dce09a8.
- 코드 서명 인증서는 지정하지 않았다. 배포는 정식 안정판이 아닌 preview다. 기본 앱 연결 변경·전체 접근성·모든 모니터 조합·반디집 전체 우위는 이번 검증 범위 밖이다.
