# ZipZip 0.2.1-preview

압축·추출 경로와 파일 목록에 접근성 이름을 추가한 Windows x64 프리뷰입니다.

- 저장·추출 경로 입력란과 찾아보기 버튼의 목적을 접근성 이름으로 제공
- 압축 형식·수준과 설정 버튼의 선택 상태를 접근성 상태로 제공
- 파일 목록 항목의 이름·종류·크기 제공, 항목 재사용 시 이전 이름 초기화
- 작업 진행률 컨트롤의 이름 제공
- 설치 파일의 숫자 버전 정보가 지정한 릴리스 번호를 따르도록 수정

검증: 앱 Release 빌드 경고·오류 0개, 기존 테스트 21개·실제 7-Zip 검사 28개·아이콘 117프레임 통과. 설치 프로그램 종료 코드 0 및 설치된 앱 DLL과 빌드 DLL의 SHA256 일치 확인. Computer Use로 설치본의 ZIP 폴더 이동, 추출 대화상자 취소, 무결성 검사, 7Z 형식 선택·생성·결과 목록 열기를 확인했습니다. ShellExtension의 기존 CS1998 경고 1개는 남아 있습니다.

한계: 창 제어 도구가 접근성 트리를 반환하지 않아 화면 읽기 프로그램의 실제 발화는 검증하지 못했습니다. 이번 패치에서 DPI 전체 조합과 탐색기 통합을 다시 실측하지 않았습니다. 0.2.0-preview에서 확인한 범위와 기존 한계는 해당 릴리스 기록을 참고하세요. 코드 서명되지 않은 프리뷰이며, 전체 UI·UX 목표는 진행 중입니다.
