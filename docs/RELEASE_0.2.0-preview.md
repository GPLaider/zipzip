# ZipZip 0.2.0-preview

아이콘과 주요 작업 화면을 정리하고 압축 안정성을 보완한 Windows x64 프리뷰입니다.

- 투명 앱 아이콘과 파일 형식별 아이콘 교체, 홈·목록·설정 배치 개선
- 폴더 압축, 암호화 목록 열기, 암호 재시도, 분할 압축 결과 열기
- 숫자 진행률·경과 시간·취소, 원본을 변경하지 않는 무결성 검사
- 기존 출력 파일 보존, 한글·특수문자 처리, 암호 실패 후 재시도 보완
- WinUI 1.8.11 포커스 수정, 페이지 초기 포커스와 Per-Monitor V2 선언
- SDK 기반 Release 설치 빌드, 7-Zip 라이선스 동봉, SHA256SUMS 제공

검증: 기존 테스트 21개·실제 7-Zip 검사 28개·아이콘 117프레임 통과. 설치본 실행·탐색기 ZIP 생성과 새 폴더 추출, 초기 Ctrl+O·Alt+Tab 복귀 후 Ctrl+N, 100/125/150% 배율 동작을 실제 창으로 확인했습니다.

알려진 한계: 코드 서명되지 않은 프리뷰입니다. 취소 시 일부 출력이 남을 수 있고 암호화 파일은 추출 전에 추가 검사를 수행합니다. 자동화 도구의 창 활성화에서는 키보드 포커스가 불안정할 수 있으나 실제 Alt+Tab 경로는 통과했습니다. 전체 접근성·모든 DPI 조합과 반디집 대비 우위는 아직 검증하지 않았습니다.

다운로드 후 SHA256SUMS.txt로 설치 파일을 확인할 수 있습니다. 파일 연결은 설치 옵션으로 선택하며 이번 검증에서 기본 앱 연결은 변경하지 않았습니다.
