# ZipZip 0.2.2-preview

현재 폴더에서 파일을 찾고 이름·원본 크기로 정렬할 수 있는 Windows x64 프리뷰입니다.

- 파일 이름 검색: 대소문자 구분 없이 검색하며 대괄호 등 특수문자를 그대로 처리
- 이름 오름차순·내림차순, 큰 파일·작은 파일 우선 정렬. 폴더는 항상 먼저 표시
- Ctrl+F로 검색창 이동, Esc로 검색 해제, 결과가 없거나 폴더가 비어 있을 때 안내
- 폴더 이동 시 검색어 초기화, 목록 갱신 시 숨은 선택이 남지 않도록 선택 초기화
- 검색창에서 복사·붙여넣기를 파일 작업 단축키가 가로채지 않도록 보완
- 목록 변경을 한 번에 알리도록 갱신 방식 변경

검증: Release 앱 빌드 경고·오류 0개. 테스트 22개, 실제 7-Zip 검사 28개, 아이콘 117프레임 통과. 설치 프로그램 종료 코드 0. Computer Use로 1,004개 항목 목록에서 Ctrl+F, 특수문자 검색, 빈 결과 안내, Esc 복원 및 작은 파일 우선 정렬을 확인했습니다.

검색 범위는 현재 폴더입니다. 이번 패치에서 모든 DPI 조합과 화면 읽기 프로그램 발화를 검증하지 않았습니다. ShellExtension의 기존 CS1998 경고 1개는 남아 있습니다. 코드 서명되지 않은 프리뷰이며 전체 UI·UX 개선 목표는 진행 중입니다.
