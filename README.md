# ZipZip

ZipZip은 한국 사용자에게 익숙한 흐름을 목표로 만든 Windows용 압축 프로그램입니다.

현재 저장소에는 다음이 포함되어 있습니다.

- WinUI 3 기반 데스크톱 앱
- 7-Zip 기반 압축/해제 백엔드
- 탐색기 우클릭 메뉴 연동
- 파일 연결 설정
- ZIP / 7Z 생성
- 다양한 포맷 열기/풀기 지원

## 현재 상태

이 저장소는 아직 `preview` 단계입니다.  
기본 기능 테스트와 UX 다듬기를 계속 진행 중입니다.
